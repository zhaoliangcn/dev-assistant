Features

不止于聊天，而是真正理解代码库

从一行代码到一个仓库，Dev-Assistant 全方位覆盖开发工作流。

🔍

代码库级理解

批量分析项目文件，构建结构与依赖图谱，符号级定位（tree-sitter 精确解析），回答不只是泛泛而谈。

batch_read_filesread_symbolglob
🔧

自动修改代码

写文件、重构、补测试、执行命令，一条指令完成从需求到落地的全流程。改动前后自动编译验证。

edit_filewrite_filecargo check
🔄

流水线执行

/pipeline 一条命令驱动六阶段工作流，上一阶段产物自动作为下一阶段上下文，断点可续跑。

6 阶段检查点恢复加权进度
🛡️

安全可控

危险操作需要审批、路径遍历防护、gitignore 感知、会话级授权缓存，权限永远在你手里。

危险审批路径验证PermissionStore
🧩

递归子代理

复杂任务自动分解：架构师 / 实现者 / 审查员 / 测试员 / 调试专家，各自独立上下文与受限工具集，深度 ≤ 3。

深度 ≤ 3后台并行 ≤ 4防无限递归
🌐

双形态运行

终端 REPL（支持 / 命令、半透明玻璃拟态）或浏览器 Web UI（axum + Vue 3 / HTMX），同一 Agent 内核。

CLIWeb UIWebSocket 流式输出
🧠

记忆系统

自动采集 → 巩固 → 去重 → 遗忘，模拟人脑记忆周期。跨会话沉淀经验，越用越懂你。

Dream 引擎跨会话自动整理
⏰

定时任务

时间轮调度引擎：cron / 间隔 / 一次性触发，Agent 或 Shell 两种执行模式，JSONL 持久化，重启恢复。

cron时间轮失败重试
🧰

技能扩展

从 Git 仓库或本地目录安装 SKILL.md 技能，无痛升级 Agent 能力边界，形成团队共享的工程经验库。

skill add/list/remove全局/项目级

一条命令，六阶段流水线

从需求到「已提交」，Dev-Assistant 自动衔接每一步，实时汇报加权进度。

> /pipeline 为项目添加一个配置文件解析模块并补全测试与文档
  1. 1
    🏗 架构设计Architect 输出模块结构、接口定义、数据流
  2. 2
    💻 代码实现Implementer 按架构落盘实现 + 单元测试
  3. 3
    🧪 测试验证运行 cargo test/clippy，验证行为符合预期
  4. 4
    🔍 代码审查Reviewer 审查质量 / 安全 / 性能，产出报告
  5. 5
    🔧 问题修复Debugger 逐条修复审查发现的问题
  6. 6
    📋 进度记录记录进度 + git commit · 整个流程可检查点续跑

Getting Started

三分钟跑起来

①

安装

# 要求 Rust 1.85+
git clone https://github.com/zhaoliangcn/dev-assistant.git
cd dev-assistant
cargo build --release
②

配置（零文件编辑）

# 方式 A：Web 零配置，浏览器内完成
dev-assistant --web
# 方式 B：交互式向导 / 脚本化一行
dev-assistant init --provider openai \
  --api-url https://api.openai.com/v1 \
  --api-key sk-xxx --model gpt-4o-mini
③

运行

# 终端交互模式（REPL）
dev-assistant

# Web UI（浏览器访问 http://127.0.0.1:8080）
dev-assistant --web --port 8080

# 单次执行
dev-assistant --message "审查一下当前项目的安全风险"

Architecture

模块化内核，职责清晰

数据流

用户输入 → repl.rs → Agent.step()
        → LLM API → 工具执行 → 结果渲染
                        ↓
  Web UI ← axum ← WebSocket / REST
        ← 复用 Agent / LlmClient / ToolRegistry

核心组件

  • Agent对话上下文 · 工具调度 · 子代理 · 压缩
  • LlmClient多 Provider · 故障转移 · 指数退避重试
  • ToolRegistry文件 / 搜索 / 符号 / 知识库 / 缓存
  • SecurityPolicy危险审批 · 路径验证 · gitignore 感知
  • Orchestrator依赖图 · 断点续跑 · 并发控制
  • Scheduler时间轮 · 持久化 · 执行器池
  • Dream记忆采集 → 巩固 → 去重 → 遗忘
  • HookManagerShell Hook 事件注入
  • SessionStoreJSONL 会话持久化，append-only
